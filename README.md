# Jungle Bell · 정글벨

설치 없이 브라우저에서 플레이하는 할리갈리 기반 비공식 팬 게임입니다. 서버 없는 1대1 컴퓨터 대전이며 온라인 멀티플레이는 포함하지 않습니다. 원작 로고·카드 이미지는 사용하지 않고 SVG 과일을 직접 그렸습니다.

## 실행

GitHub 저장소를 내려받았다면 먼저 `game-assets.zip`을 같은 폴더에 풀어 `assets/`와 `tests/`를 복원하세요. 배포 과정에서는 자동으로 압축을 풉니다. 이미지나 소리를 수정했다면 이 압축 파일도 갱신하세요.

Node.js 없이도 Python 3으로 실행할 수 있습니다.

```sh
python3 -m http.server 4173
```

브라우저에서 http://localhost:4173 을 여세요. 파일을 더블클릭하는 file:// 실행은 모듈과 카메라 제약 때문에 지원하지 않습니다.

## GitHub Pages 공개

- 게임 주소: https://qortjsduf1.github.io/jungle-bell/
- 저장소: https://github.com/qortjsduf1/jungle-bell

Settings → Pages에서 GitHub Actions를 배포 소스로 사용합니다. main 브랜치에 변경 내용을 올리면 테스트를 거쳐 자동 배포됩니다.

## 플레이

- 닭 → 고양이 → 염소 → 말 → 코끼리. 각각 다른 소개·놀림 대사와 AI 반응시간을 사용합니다. 모든 단계는 자유롭게 선택할 수 있고 승리하면 다음 단계 버튼이 나옵니다.
- 휴대폰: 게임 테이블의 빈 곳 또는 카드를 터치하거나 가운데 종을 누릅니다. 스크롤·드래그·시작·일시정지 버튼은 종 입력에서 제외합니다.
- PC: 스페이스바 / 게임 테이블 우클릭 / 화면 종 클릭 / 웹캠에서 손 올리기.
- 모바일 세로 화면에 맞춰 테이블과 조작 버튼 배치를 줄였습니다. 브라우저 390×844 화면에서 배치 및 포인터 입력을 확인했으며 실제 iPhone/Android 기기의 터치 검증은 아직 하지 않았습니다.
- 휴대폰에서 PC의 localhost 주소로는 접속할 수 없습니다. 위 GitHub Pages 배포 후 생성되는 HTTPS 주소를 휴대폰 브라우저로 열어주세요.
- 자동 공개 간격: 0.8, 1, 1.8초 (기본 1초). 내 카드와 상대 카드가 번갈아 공개됩니다.
- 같은 과일이 정확히 5개인 경우만 정답. 덮인 카드의 과일은 합산하지 않습니다.
- 56장, 4가지 과일. 과일별 1/2/3/4/5개 카드가 5/3/3/2/1장씩 있습니다.
- 끝까지 승부: 정답이면 두 공개 더미를 손패 맨 아래에 넣고 계속 진행합니다. 오답은 손패 1장을 상대에게 줍니다.
- 마지막 카드 공개 직후에는 바로 탈락하지 않고 다음 공개 시점까지 종을 칠 수 있습니다. 그때 손패가 0장이면 패배합니다. 카드 수집·벌칙 후 한쪽 손패가 0장이 되는 경우에도 종료합니다.
- 원작의 2인 최종 라운드 종료 규칙 대신 사용자가 요청한 연속 대전 규칙을 적용했습니다.
- 동물마다 승리·패배 짤 2개씩, 총 10개. 내가 이기면 아쉬운 표정, 동물이 이기면 약 올리는 표정과 대사가 나타납니다. 앉은 동물이 원근 회전과 확대를 거쳐 사진으로 바뀌고 약 2.2초 후 의자로 돌아갑니다. 입력은 잠시 잠기고 이후 자동 공개가 이어집니다.
- 은색 금속 돔과 검은 받침의 탁상 종을 SVG로 그렸습니다.
- 타원형 펠트 탁자와 나무 테두리, 맞은편 의자에 앉은 동물 캐릭터를 배치했습니다. 상대 선택에 따라 닭·고양이·염소·말·코끼리 SVG 캐릭터가 바뀝니다.
- 일시정지, 탭 이탈 시 자동 정지, 효과음 끄기, 세션 내 최고 반응 기록을 지원합니다.

캐릭터는 명암을 넣은 SVG와 CSS 원근·회전으로 입체감을 표현한 2.5D 연출입니다. 의자는 고정되어 있으며 동물만 변신합니다. 동작 줄이기 설정에서는 회전 없이 리액션을 표시합니다.

## 웹캠

카메라 켜기를 누르면 MediaPipe 0.10.21 및 Google의 손 인식 모델을 다운로드하고 카메라 권한을 요청합니다. HTTPS(GitHub Pages) 또는 localhost와 인터넷 연결이 필요합니다. 카메라 영상은 브라우저에서 처리하며 저장하거나 외부에 보내지 않습니다. 외부 모델·글꼴 다운로드 요청은 발생합니다.

손목을 화면 아래 62% 지점보다 낮게 보인 뒤 위쪽 38% 선 위로 올리세요. 연속 2프레임을 확인하여 오작동을 줄입니다. 한 번 울린 뒤 손을 내려야 다시 울립니다. 어두운 환경, 손 가림, 기기 성능에 따라 인식과 반응 지연이 달라질 수 있습니다. 카메라 시작 시 진행 중 게임은 일시정지됩니다.

실제 사용자의 손 동작과 카메라 권한 흐름은 현장 검증이 필요합니다. 웹캠이 없어도 다른 조작으로 모든 게임 기능을 사용할 수 있습니다.

## 검증

```sh
npm test
```

의존성 설치 없이 Node.js 내장 테스트로 카드 구성, 정확히 5 판정, 승리 수집, 오답, 복귀, 무작위 게임에서 56장 보존을 확인합니다. 브라우저에서 시작, 자동 공개, 정답·오답 리액션 사진, 종 판정 후 이어지는 경기, 일시정지 흐름을 확인했습니다. 10개 엔진 테스트가 통과했습니다.

## 파일

- `index.html`, `style.css`: 반응형 한국어 화면
- `engine.js`: UI와 분리한 카드·판정 엔진
- `app.js`: 동물 AI, 입력, 카메라
- `audio.js`: 카드 넘김, 종, 동물별 약 올리는 승리 멜로디 합성
- `assets/reactions/`: 동물별 리액션 이미지 10개
- `ASSET-SOURCES.md`: 리액션 이미지 출처
- `tests/engine.test.mjs`: 게임 규칙 테스트
- `.github/workflows/pages.yml`: 테스트 후 Pages 배포

## 효과음

카드 공개 시 종이 넘기는 잡음과 가벼운 타격음을 합성합니다. 상대가 이기면 동물 울음과 약 올리는 멜로디가 납니다. 상대가 지면 동물별 패배 반응음이 납니다. 닭·고양이는 실제 녹음의 속도·반복을 바꾸어 표현하고 염소·말·코끼리는 합성한 울음입니다. 카드·종·멜로디는 기기에서 합성합니다. 닭과 고양이는 함께 배포되는 WAV 녹음 파일을 읽어 재생하며, 출처와 라이선스는 ASSET-SOURCES.md와 게임 방법에 표시합니다. 게임 시작 또는 소리 켜기 조작으로 오디오를 활성화하며, 상단 소리 끄기는 재생 중인 효과음을 포함해 전체 출력을 음소거합니다. 실제 휴대폰의 무음 설정과 브라우저에 따른 청취 검증은 아직 필요합니다.

카드 공개 속도: 기본 1초, 빠르게 0.8초, 느긋하게 1.8초. 시작 후 첫 카드는 0.6초 뒤 공개하며, 종 판정 후에는 리액션 복귀가 끝나는 2.3초 시점에 바로 다음 카드를 공개합니다.

## 자유 종료와 단계 선택

게임 중·일시정지 중·리액션 중 언제든 그만두기를 누를 수 있습니다. 진행 중인 판, 예약된 AI 입력, 리액션과 효과음을 중단하고 카메라도 꺼집니다. 1~5단계 버튼은 항상 열려 있으며 다른 단계를 누르면 기존 판을 종료하고 새 상대의 시작 준비 상태가 됩니다. 확인창 없이 전환되므로 현재 카드 진행은 초기화됩니다. 브라우저에서 진행 중 1→5단계 전환과 그만두기 후 종 비활성화를 확인했습니다.
